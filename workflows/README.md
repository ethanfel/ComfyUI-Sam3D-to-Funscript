# Start here

Drag one of these workflows into ComfyUI:

| Workflow | Use it for |
|---|---|
| [01 · Single video](01_single_video.json) | Track a video, stabilize sections, or author audio patterns in Motion Studio. |
| [02 · Folder library](02_folder_library.json) | Review local clips, process subfolders in bulk, or browse and review Civitai downloads. |
| [03 · H3 Animator project](03_h3_project.json) | Work in page/panel order, check drawings, exclude pages or takes, and save reviewed scripts beside H3 videos. |

All start with **prepare**. Choose your video, folder or H3 project, click **Run**, then open the workspace from the node. Motion Studio is included; no separate export node is required. Save your workflow to return to its editing session.

Each template starts with blank media paths and no saved session. Your existing saved workflows still work.

For individual node integrations, see [advanced recipes](../extras/advanced/README.md). [API prompts](../extras/api/README.md) are separate from these canvas files.
